# Windows PC Toolkit 3.0.1

Correctness audit of the complete dashboard and all five tool areas before further feature expansion. Download **Windows-PC-Toolkit-3.0.1.zip**, extract the complete folder and run **START_TOOLKIT.bat**. Close older copies first. Windows 11 and built-in Windows PowerShell 5.1 are the main target.

- Fix cleanup escaping through junctions and make Windows.old report-only; match scan results to aged-file deletion and preserve replacements during registry recovery.
- Fix privacy backups that could not undo their own changes; preserve registry types, arrays and delayed service startup; report denied writes.
- Correct Quad9 secondary IPv6 to `2620:fe::9`; require typed DoH APIs, preflight adapter families and verify changes and rollback.
- Fix repair summary crashes and false success reports; preserve native DISM/SFC results and restart requirements, scope Store repair to the current account and validate gaming recovery snapshots.
- Fix reviewed-only optimization and preview, worker failure reporting, empty undo, task identity matching and AppX backup tampering checks.
- Fix all 12 launchers' path/elevation handling and exit codes; preserve the originating account for user-scoped changes.
- Add bounded optional diagnostic logs and native failure-path checks. No new debloat features or runtime dependencies.

408 local regression assertions passed; administrative CI runs 396 assertions in each of the canonical and friendly layouts. Tests use real disposable registry/files, CMD, PowerShell, WPF, workers and native-process fixtures. Live mutation commands are intercepted. [Audit](../AUDIT_2026-10-10.md), [validation and limits](../../VALIDATION_REPORT.md).

Existing reports and backups under `%ProgramData%\WindowsPCToolkit` remain available. App backups support package re-registration, not app-data recovery. Deleted temporary/cache files are not recoverable through undo. Interactive UAC, live corruption repair, AppX/Recall/provider outcomes and FPS gains are not certified by these tests.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`; detailed logging is off by default. Enable `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1` when reproducing a problem.

We recommend [optimizerDuck](https://github.com/itsfatduck/optimizerDuck) for broader Windows customization and management. Obtain it from its own releases; no Duck executable or source is bundled.

The release attaches SHA-256 checksums and exact commit/CI provenance. Its portable archive contains application scripts, shared modules and documentation; development tests and CI files remain in the matching GitHub source.
