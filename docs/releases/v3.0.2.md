# Windows PC Toolkit 3.0.2

Safety fixes from a second audit of the complete kit. Download **Windows-PC-Toolkit-3.0.2.zip**, extract the whole folder and run **START_TOOLKIT.bat**. Close older copies first; keep the shared Modules folder with the tools.

- Validate complete recovery records before changes; refuse malformed or out-of-scope registry, task, service, boot, adapter and DNS state.
- Require a unique, complete AppX backup hash inventory and check existing Suite state permissions.
- Reject linked recovery/cache paths; prevent thumbnail/icon cleanup escaping through Explorer junctions.
- Stop repair actions when AI/DNS snapshot saving fails; verify restore-point creation instead of trusting a warning/no-op.
- Restore disabled-but-running services correctly and replace the obsolete Edge telemetry policy.
- Preserve old cleaner manifests for manual recovery and retire their unsafe automatic file/whole-key import; current typed undo remains supported.
- Fix native DNS capture and historical recovery when Windows registry addresses contain trailing terminator padding.
- Add native regression fixtures for the newly reproduced failures. No feature expansion or new runtime dependencies.

[Audit findings](../AUDIT_2026-10-11.md), [validation and runtime limits](../../VALIDATION_REPORT.md). Tests use disposable registry/files, real junctions, WPF/native processes and intercepted mutation commands. Exact commit, successful CI links, assertion counts, archive size and SHA-256 are in the attached `release-provenance.json`.

Existing reports and backups remain available under `%ProgramData%\WindowsPCToolkit`. Run one component operation at a time; advanced snapshot restore can replace later manual changes and requires confirmation. App backups support package re-registration, not app-data recovery. Deleted temporary/cache files are not restored by undo. Live Windows repair, DNS/AppX/Recall outcomes, interactive UAC and FPS gains are not certified by the fixtures.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging is off by default; enable `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1` for reproduction.

We recommend [optimizerDuck](https://github.com/itsfatduck/optimizerDuck) for broader Windows customization. Obtain it from its own releases; no Duck executable or source is bundled.
