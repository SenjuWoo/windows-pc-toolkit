# Windows PC Toolkit 3.3.0

PC Cleaner 1.3.0: cache-scanner correctness fixes and a Skyrim & Modding Cleanup page. Extract the complete **Windows-PC-Toolkit-3.3.0.zip** into a new folder and run **START_TOOLKIT.bat**; close older dashboards first. Existing reports and backups in `%ProgramData%\WindowsPCToolkit` remain available.

## Cache Explorer fixes

- A wildcard directory pattern (the Epic layout) is measured as directories, not as files, so the scan no longer shows zero bytes for a cache it would clean.
- The scan enumerates depth-first and stops at the cap; a capped row is labelled as a lower bound.
- Age rules apply to every file immediately before deletion. A fresh file inside an old folder survives, and the eligible estimate matches the bytes actually removed.
- Reports are unique per run and show eligible bytes next to total found. **Review every candidate** prints each path, its source, its rebuild impact and the age rule.
- Steam is found through the registry and every `libraryfolders.vdf` entry, and each library root is validated as a local fixed drive. VRChat honours a configured local `cache_directory`.
- Steam staging temp and the Epic webcache folder are now report-only: staging can hold an unfinished update, and the browser `WebCache` guard also covers Epic's folder name. Gradle and Unreal caches require their editor or JVM to be closed.

## Skyrim & Modding Cleanup

New menu `[9]`. It resolves the Windows Documents known folder and inspects only:

- `My Games\Skyrim Special Edition\SKSE` and `My Games\Skyrim VR\SKSE` - SKSE and plugin `.log` files, including rotations.
- `My Games\Skyrim Special Edition\Logs\Script` and the VR equivalent - `Papyrus*.log` files.

Two levels: **SAFE** deletes matched logs older than seven days; **HARD** deletes every matched log and requires the game and modding tools to be closed. Only `.log` and `.logN` files are eligible. Saves, `.ini`, `.json`, `.toml`, `.yaml`, `.dll`, `.pex`, `.psc`, archives and unknown file types stay, including inside the SKSE folder.

This is the single approved exception to the Documents protection, and it is revalidated per file: the path must be a direct child of an approved game-log folder, match the log pattern, be a regular file and have no reparse point in any parent. A Documents folder redirected to a cloud-synced location is report-only. Mod Organizer 2 and Vortex data folders are measured but never deleted.

## Limits

No live cache or Skyrim log was deleted while validating; every check ran on disposable TEMP fixtures. Sizes are scan-time estimates and a cache can change before deletion. MO2, Vortex, DynDOLOD, xEdit and other tool logs are not auto-detected — those folders are user-selected and remain report-only. Coverage is finite: unlisted games and tools are simply not in the catalog.

[Validation and runtime limits](https://github.com/SenjuWoo/windows-pc-toolkit/blob/v3.3.0/VALIDATION_REPORT.md). Exact release commit, CI links and hashes are attached in **release-provenance.json** and **SHA256SUMS.txt**.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging: `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1`.
