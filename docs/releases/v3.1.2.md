# Windows PC Toolkit 3.1.2

Accessibility and release-tooling release. Extract the complete **Windows-PC-Toolkit-3.1.2.zip** into a new folder and run **START_TOOLKIT.bat**; close older dashboards first. Existing reports and backups in `%ProgramData%\WindowsPCToolkit` remain available.

- Screen readers now hear what each list and picker is for: the OneDrive, startup, app, recovery and service grids, the adapter and DNS provider selectors, and the operation result log carry accessible names. Buttons already expose their visible text.
- A validation gate fails when the module version, the dashboard label and the changelog's top entry disagree, so a build cannot misreport its own version.
- The release builder and the release steps ship with the source, so the payload-to-commit check in `release-provenance.json` can be reproduced outside the author's machine.
- No optimization, repair, cleanup, debloat or DNS behaviour changed.

Nothing in this release touches OneDrive, DNS, services, the registry or files by itself. The [OneDrive folder preflight](https://github.com/SenjuWoo/windows-pc-toolkit/blob/v3.1.2/docs/ONEDRIVE_RECOVERY.md) and the earlier safety bounds are unchanged.

[Validation and runtime limits](https://github.com/SenjuWoo/windows-pc-toolkit/blob/v3.1.2/VALIDATION_REPORT.md). Fixture checks do not prove a live OneDrive migration, uninstall, Windows repair or performance improvement. Exact release commit, CI links and hashes are attached in **release-provenance.json** and **SHA256SUMS.txt**.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging: `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1`.
