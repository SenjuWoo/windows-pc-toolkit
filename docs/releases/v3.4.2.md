# Windows PC Toolkit 3.4.2

PC Cleaner 1.4.2: one missing Steam shader-cache folder no longer disables the whole category, and the library list is re-resolved at delete time. Extract the complete **Windows-PC-Toolkit-3.4.2.zip** into a new folder and run **START_TOOLKIT.bat**; close older dashboards first.

## Steam multi-library shader cache

A Steam install usually has one library with a shader cache and others without: a library holding only an untouched game, or a machine where shader caching is off. The catalog listed `steamapps\shadercache` for every library whether or not it existed, and the validator rejected the missing ones — so a single absent folder blocked every library's shader cache, while the scan still showed measured bytes. The row was advertised as unusable while its numbers said otherwise.

- Only libraries that actually have a shader cache are listed now.
- At validation, folders that exist must still pass the full Steam policy; missing ones are skipped. A row with nothing present reports "No cache folder present on this PC" instead of pretending to be cleanable.
- **The library list is re-resolved immediately before deletion.** The roots captured at scan time are no longer the authority: a library removed from Steam, unplugged, or repointed between scan and clean is refused, and its files survive.
- Unchanged: Program Files protection everywhere else, `steamapps`, `steamapps\common`, `compatdata`, manifests, installers and update staging stay out of reach; junctions are never traversed; the STRICT confirmation and Steam process check still apply.

Verified in fixtures: two libraries with one populated, two populated, a library that vanished from the mapping after the scan, a folder merely named like a shader cache, and a junction.

## Limits

No live Steam library, cache, game or modding log was deleted while validating; every check ran on disposable TEMP fixtures. Steam's own library list (registry plus `libraryfolders.vdf`) is the authority, so a library that Steam does not report is out of scope. Sizes are estimates, there is no undo, and shader recompilation cost was not measured.

[Validation and runtime limits](https://github.com/SenjuWoo/windows-pc-toolkit/blob/v3.4.2/VALIDATION_REPORT.md). Exact release commit, CI links and hashes are in **release-provenance.json** and **SHA256SUMS.txt**.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging: `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1`.
