# Windows PC Toolkit 3.1.1

Corrects the OneDrive preflight in 3.1.0. Extract the complete **Windows-PC-Toolkit-3.1.1.zip** into a new folder and run **START_TOOLKIT.bat**; close older dashboards first. Existing reports and backups remain in `%ProgramData%\WindowsPCToolkit`.

- Reject uncertain folder locations, including relative/unresolved paths, missing directories and links. Check modern local Documents/Pictures/Music/Videos aliases too, while preserving valid custom local folders.
- Recheck folder status when opening the uninstall shortcut. The toolkit opens Installed apps only; it does not run an uninstaller.
- Count cloud placeholders before reparse filtering and clearly mark incomplete scans. Linked and virtual directories are not followed and file contents are not opened.
- Replace the unsafe automatic registry restore with recovery instructions. Older restore requests refuse before writing. Files, original paths and old journals are preserved.
- Already-local folders need no OneDrive sign-in. With active backup, use Microsoft's Manage backup flow and download cloud-only data first if prompted. **Only on my PC** removes the OneDrive copy; keep an independent backup if you need both.

[Recovery instructions](../ONEDRIVE_RECOVERY.md) · [Validation and runtime limits](../../VALIDATION_REPORT.md). Fixture checks do not prove a live OneDrive migration, uninstall, Windows repair or performance improvement. Exact release commit, CI links and hashes are attached in **release-provenance.json** and **SHA256SUMS.txt**.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging: `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1`.
