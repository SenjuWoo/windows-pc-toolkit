# Windows PC Toolkit 3.1.0

OneDrive folder protection for a fresh Windows install or an existing PC. Download **Windows-PC-Toolkit-3.1.0.zip**, extract the whole folder and run **START_TOOLKIT.bat**. Close older copies first; keep the shared Modules folder with the tools.

Sign in to OneDrive and choose **Only on my PC** for Desktop, Documents, Pictures, Music and Videos before uninstalling it. Uninstalling first leaves those paths pointing at OneDrive.

- The OneDrive folders page reads those five locations and says whether each one is on this PC.
- The known-folder lock writes `KFMBlockOptIn` value 1 only after every folder is already local or in a custom folder. It refuses while a folder still points at OneDrive, while a folder location is missing, or while `KFMBlockOptOut`, `KFMSilentOptIn` or `KFMOptInWithWizard` is set. It does not move or delete files.
- Uninstall stays unavailable until the folders are safe and OneDrive is installed. The toolkit then opens Installed apps. It does not run an uninstaller.
- If OneDrive is already gone and a folder still points at it, Restore local locations rewrites only those paths and leaves the files where they are. Sign out afterwards and move leftovers yourself. That report is not undone.
- Optimize now runs this lock first, then the previous recommended gaming, cleanup, registry-care and consumer-app actions.

[Validation and runtime limits](../../VALIDATION_REPORT.md). Tests use disposable registry and a temporary profile. No live uninstall, shell-folder rewrite or file deletion is part of the check. Exact commit, CI links, archive size and SHA-256 are in the attached `release-provenance.json`.

Existing reports and backups remain available under `%ProgramData%\WindowsPCToolkit`. Run one component operation at a time. App backups support package re-registration, not app-data recovery. Deleted temporary files are not restored by undo.

Diagnostics: `%LOCALAPPDATA%\WindowsPCToolkit\Logs`. Detailed logging is off by default; enable `-DebugLog` or `WINDOWS_PC_TOOLKIT_DEBUG=1`.

We recommend [optimizerDuck](https://github.com/itsfatduck/optimizerDuck) for broader Windows customization. Obtain it from its own releases; no Duck executable or source is bundled.
