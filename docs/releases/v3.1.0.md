# Windows PC Toolkit 3.1.0

OneDrive folder protection for a fresh Windows install or an existing PC. This file describes the source tree. It is not a published ZIP until the GitHub release exists.

Sign in to OneDrive and choose **Only on my PC** for Desktop, Documents, Pictures, Music and Videos before uninstalling it. The toolkit will not lock those folders, and will not send you to Installed apps, while any of them still point at OneDrive. It does not run an uninstaller and it does not delete files.

If OneDrive is already gone and a folder path still points at it, **Restore local locations** rewrites only those locations and leaves the files in the old folder. Sign out afterwards and move leftover files yourself. That report is not undone.
