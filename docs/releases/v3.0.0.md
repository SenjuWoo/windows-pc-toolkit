# Windows PC Toolkit 3.0.0

Portable Windows gaming, debloat, privacy, cleanup and repair now share one native WPF dashboard. No installer, account, advertising or resident agent.

Download **Windows-PC-Toolkit-3.0.0.zip**, extract the complete folder, and run **START_TOOLKIT.bat**. Windows 11 is the main target; use built-in Windows PowerShell 5.1. Close older copies before upgrading. Existing reports/backups under `%ProgramData%\WindowsPCToolkit` are preserved. Individual archives from older releases lack the current shared modules/dashboard.

## Changes

- Six pages organize optimization, startup/tasks, app debloat, encrypted DNS, recovery/reports and repair/tools.
- Optimize now combines ten recommended actions, including Game Mode, promotions/privacy controls, aged temporary cleanup, targeted registry repair, modern Copilot/consumer-app removal, Recall disable and Edge built-in AI controls. Preview and nine optional choices let you customize the plan.
- Before-write typed journals, read-back, conflict-aware undo and verified package copies support recovery. Store, Xbox, Gaming Services, Defender, Update, drivers and separate local-AI model stores remain protected in the recommended profile.
- Quad9 and AdGuard profiles replace new Mullvad applies ahead of its public DNS retirement. Existing entries update in place; GUID/per-family restore and verification failures are handled explicitly.
- Repair runs DISM before SFC, preserves actual output and reports restart requirements. Fix the unsigned stay-awake flag failure affecting dashboard repair and game-session mode; cleanup releases the shared operation lock even if stay-awake release fails.
- Decode SFC's redirected UTF-16LE output correctly so repair results remain readable; test the real read-only help/error output as well as native fixtures.
- Cleaner, privacy and corruption-fixer consoles gain guarded cleanup and checked recovery/failure handling. The complete bundle retains advanced gaming, hardware and repair tools.
- **114 native Windows regression/boundary checks** cover real disposable registry/files, package-copy hashes, fresh spaced/Unicode paths, actual WPF/jobs, native stay-awake and repair subprocesses. CI repeats the suite in canonical and friendly installed layouts.

We recommend **[optimizerDuck](https://github.com/itsfatduck/optimizerDuck)** for broader Windows customization and management. Download it from [its own releases](https://github.com/itsfatduck/optimizerDuck/releases); no Duck binary or GPL source is bundled. [Feature coverage](../FEATURE_COVERAGE.md).

## Recovery and verification

App removals name installed apps for confirmation and affect the current account. Verified backups support package re-registration, not app-data recovery; dependencies/servicing can prevent reinstall. Deleted temp/cache files, Recall snapshots and built-in browser models are not restored. No restart is forced. No universal compatibility or measured FPS claim is made. [Validation details](../../VALIDATION_REPORT.md).

`SHA256SUMS.txt` lists the ZIP/provenance hashes. `release-provenance.json` records the exact source commit and successful CI runs. The archive is built from that commit, extracted and compared against every tracked Git blob, tested, then downloaded after publication for hash verification.
